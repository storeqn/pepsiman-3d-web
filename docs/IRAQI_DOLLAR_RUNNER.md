# صايد الدولار 3D — فرع التحويل العراقي

الشعار: **الحق الدولار قبل لا يطير!**

## التحويل المنفذ
- شخصية عراقية أصلية، مصنوعة هندسياً داخل Babylon.js، بدشداشة بيضاء ذات ثنيات وشماغ أحمر/أبيض وعقال وحذاء، مع نقاط مفاصل تتحرك للجري والقفز والانزلاق والاصطدام.
- انطلاقة سرعة 14 متر/ثانية، وتسارع تدريجي إلى حد أعلى 21 متر/ثانية، مع كاميرا Third Person متتبعة وتغيير FOV محدود.
- استبدال حلقات الطاقة بمجسمات أوراق نقدية دوارة تحمل رسماً أصلياً مستوحى من شكل ورقة نقدية افتراضية، مع وميض جمع وصوت وعدّاد دولار ($100 لكل رزمة).
- ألوان شوارع وأسواق نهارية، ولافتات عربية ومحلات، وتكاسي صفراء، وعوارض وحواجز، مع الاحتفاظ بالتوليد المرحلي للبيئة ونظام تجميع المجسمات الثابتة حسب الخامة.
- تعريب شاشة البداية والقوائم والعدادات مع «يلا نركض!» والإعدادات المتاحة.
- الإبقاء على اللمس ولوحة المفاتيح والصوت وإعدادات Auto/Low/Medium/High ونتائج التخزين المحلية.
- الحفاظ على النشر الساكن في Cloudflare Pages وعلى الخدمة دون اتصال، مع تنظيف كاش PWA القديم عند تبديل الإصدار.

## الحالة الفعلية والقيود الفنية
- الشخصية نموذج procedural articulated وليست بعد GLB فنياً منحوتاً أو ذا skinning animation احترافي. يظل استبدالها بشخصية مخصصة عالية التفاصيل مهمّاً لمستوى جودة تجاري.
- البيئة مبنية على أشكال وخامات PBR ورسم علامات أصلي؛ لا توجد صور أو أصول طرف ثالث غير مرخصة.
- الإضاءة والخامات تحسنت على مستوى البرمجة، لكن جودة iPhone الفعلية ومعدل FPS لا يُعلنان دون اختبار على أجهزة فعلية.
- لا يوجد نمط متعدد اللاعبين؛ اللعب يعمل من المتصفح أو كتطبيق ويب PWA بلا خادم.
- مرحلة اللعب الحالية 2400 متر؛ المراحل الأخرى معلّمة بوصفها قيد التطوير.

## الفحص
```sh
npm ci
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

يمكن رؤية نتائج الفحص الآلي ضمن GitHub Actions لفرع وPull Request هذا؛ اختبار يدوي على iPhone لا يزال مطلوباً.
