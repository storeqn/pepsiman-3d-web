## اختبارات قابلة لإعادة التشغيل

- `npm test`: 12 اختباراً لوحدة المنطق. تغطي ثبات الحركة بترددات عرض مختلفة، الحركة الحرة، الحدود، القفز ومنع القفزة الثانية، انتهاء الانزلاق، الحد من تعويض الوقت، التصادم، المرور تحت العارضة، طريق آمن حتى النهاية، والتحقق من البيانات والحفظ وتلف التخزين.
- `npm run build`: فحص TypeScript strict وبناء الإنتاج. يوجد تحذير حجم لحزمة المحرك الرئيسية (نحو 1.15 MB قبل الضغط و292 KB gzip)، وليس خطأ بناء.
- `npm run test:e2e`: اختبارات Playwright للحركة بلوحة المفاتيح والقفز والانزلاق والتوقف والتصادم والفوز والحفظ والقوائم، وPointer swipes بعرض شاشة 390×844، واختبار إنتاج/PWA/offline.
- الفوز في الاختبار الآلي يُتحقق منه بتسريع خطوات المنطق عبر hook متاح في Vite DEV فقط؛ لا يوجد hook أو غش اختبار في بناء الإنتاج. لا يمثل هذا جلسة لعب يدوية كاملة لمدة 3 دقائق.
- تصيير Chromium المستخدم محلياً عبر SwiftShader برمجياً. لا يجوز اعتبار FPS في تلك البيئة قياساً لأداء هاتف فعلي.
- صور الفحص ينتجها Playwright داخل `test-results/` وهي مستثناة من git. يمكن تشغيل الفحوص لتوليد صور جديدة.

## نتائج التحقق المحلي

- نجحت اختبارات الوحدة: 12/12.
- نجح فحص TypeScript strict وبناء الإنتاج.
- نجحت اختبارات المتصفح الثلاثة: سيناريو الكمبيوتر، السحب بحجم هاتف، والإنتاج مع Service Worker وإعادة تحميل كاملة دون إنترنت.
- لم تُسجل أخطاء JavaScript حرجة في السيناريو المختبر، وشمل اختبار الإنتاج رصد أخطاء Console.
- جرى فحص صور القائمة واللعب على الكمبيوتر والشاشة العمودية، مع تحسين إضاءة المشهد وخامة الطريق.
- تعذر تنزيل Chromium بالطريقة القياسية في البيئة؛ استُخدم Chromium محلي بديل عبر متغير `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` دون إضافة الحزمة البديلة إلى المشروع.

## متبقي قبل قبول اللعبة النهائية

1. شخصية GLB احترافية أصلية أو مرخصة وخرائط Normal/Roughness وRig وحركات كاملة مع blending.
2. بيئة فنية ذات تنوع أعلى وتفاصيل أفضل، GPU instancing وLOD شامل، رفع وخفض الطريق والجسور والأنفاق والمركبات المتحركة.
3. تنفيذ Highway Escape وConstruction Chaos وNeon Night وFinal Chase، وتدرج صعوبة وإشارات المخاطر والأحداث والمطاردة والنهاية الخاصة.
4. غبار واصطدامات بصرية وحركات Hit/Crash/Victory، موسيقى ومؤثرات أصلية نهائية.
5. قياسات 30/60FPS والذاكرة والحرارة على iPhone Safari وAndroid، والتحقق من اللمس الحقيقي والتثبيت والتحديث والعمل دون إنترنت على الأجهزة.
6. نشر Cloudflare Pages من المستودع وفحص رابط الإنتاج. لم ينفذ نشر خارجي في هذه الجلسة.

لا تُظهر الواجهة المراحل غير المنفذة كأنها قابلة للعب، وتعرض حالة الأصول المؤقتة صراحة.
