# سجل الأصول

جميع الرسومات الحالية مولدة خصيصاً لهذا المشروع، دون نسخ ملفات ألعاب أخرى أو استخدام علامات تجارية.

| الأصل                             | المصدر                                            | الحالة                        |
| --------------------------------- | ------------------------------------------------- | ----------------------------- |
| الشخصية الفضية والزرقاء           | `src/world/character.ts`، مجسمات متصلة بعقد مفاصل | مؤقت، ليس نموذج شخصية نهائياً |
| الأبنية والأثاث والسيارة والعقبات | `src/world/world.ts`                              | نماذج إجرائية مؤقتة           |
| خشونة الأسفلت المرئية             | DynamicTexture محلي حتمي                          | مؤقت، ليس مجموعة PBR مصورة    |
| البيئة الانعكاسية                 | `public/environment/*.png`، تدرجات أصلية          | مكعب منخفض الدقة، لا HDR مصور |
| أيقونات التطبيق                   | `public/icon-*.png`، رسم حرف S أصلي               | صالحة للمرحلة التجريبية       |
| المؤثرات والموسيقى                | Web Audio oscillator synthesis                    | تركيب أصلي بسيط ومؤقت         |
| الخط                              | خط نظام Tahoma/Arial، غير مرفق                    | يعتمد على جهاز المستخدم       |

## عقد استبدال الشخصية

يلزم ملف `runner.glb` أصلي أو مرخص بترخيص واضح محفوظ هنا. محور Y للأعلى، طول نحو مترين، pivot عند القدمين، وجه أمامي باتجاه +Z. تُسمى حركات AnimationGroups: Idle, Run, Sprint, Jump, Fall, Landing, Slide, Dodge, Hit, Stumble, Recover, Crash, Victory. الحركات in-place، لأن نظام اللعبة يدير الإزاحة.

يجب إضافة تحميل GLB وإظهار تقدم التحميل وAnimation Blending والتحقق من المقياس والاتجاه. حزمة `@babylonjs/loaders` موجودة، لكن مسار تحميل GLB **ليس منفذاً بعد**. يُحفظ الترخيص والمؤلف ورابط الأصل وتاريخ الحصول عليه عند إضافة أي أصل خارجي.

يلزم Metallic/Roughness/Normal maps، ضغط KTX2 عند توفر دعم الأجهزة، وLOD وموازنة عدد المثلثات بقياسات على أجهزة الهاتف. لا تُستبدل hitboxes العادلة بتصادم مثلثات الشخصية.

## البيئة النهائية

مجموعة Modular بأبعاد حقيقية ومتنوعة، سيارات وشاحنات وحافلات، جسور وأنفاق ومنحدرات ومواقع بناء ونيون، مع مستويات تفصيل وinstancing. البيئة الحالية ليست مدينة نهائية ولا تحتوي هذه الفئات كلها.
